Pill 1.0.0 beta — first public build.

A dynamic island for Windows: a black capsule at the top of the screen, media player, live equalizer, ambient color from the active window, a drop shelf for files, saved settings, autostart, and signed OTA updates from GitHub Releases.

This release was put together in a hurry. It is beta, not a final version. Some decisions may change significantly in patches: ambient color behavior, animation timing, menu layout, settings format, installer, and the update flow.

Install with Pill.Installer.exe or Pill.exe --install.
